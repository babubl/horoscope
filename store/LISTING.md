### Data safety form

The app calculates everything on the phone. Two optional features send data off the device:

| Data type | Collected? | Why / notes |
|---|---|---|
| Location → Approximate location | **Yes** — optional, not shared, processed ephemerally, not stored | The place name the user types is sent to Open-Meteo to look up coordinates. Purpose: App functionality. |
| Personal info → Name | **Yes** — optional, processed ephemerally | Only when the user adds their own Gemini key and asks for an AI reading; the chart with the name goes to Google Gemini. Purpose: App functionality. |
| Everything else | No | No accounts, analytics, crash logs or identifiers are collected. |

- Is data encrypted in transit? **Yes** (HTTPS).
- Can users request deletion? Answer **Yes / not applicable** — nothing is stored by the developer; clearing app data removes everything on the device.

If you later remove the AI reading from the app, change "Name" to not collected.
