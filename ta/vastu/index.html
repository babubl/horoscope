பஞ்சாங்கம்நாட்காட்டிஜாதகம்திருமணப் பொருத்தம்பரிகாரம்கோயில்கள்வாஸ்துபண்டிகைகள்நட்சத்திரங்கள்ராசிகள்குழந்தை பெயர்
முகப்பு › வாஸ்து

வாஸ்து சாஸ்திரம் — எளிய தமிழ் வழிகாட்டி

வீடு கட்டும் முன், வாங்கும் முன், அல்லது இருக்கும் வீட்டைச் சீர் செய்ய — எட்டுத் திசைகளும் நடுவும் சொல்லும் பாரம்பரிய நெறிகள், ஒவ்வொன்றின் காரணத்துடன்.

🏠உங்கள் வீட்டைச் சரிபாருங்கள்ஒவ்வொரு அறையும் எந்தத் திசையில் இருக்கிறது என்று தொட்டுக் காட்டுங்கள் — உடனே மதிப்பெண்ணும் தீர்வுகளும்.🗓️வாஸ்து நாள் 2026–27ஆண்டுக்கு எட்டு நாட்கள், பூமி பூஜைக்கான நேரத்துடன்.🛏️அறை வாரியாக வாஸ்துதலைவாசல், பூஜை அறை, சமையலறை, படுக்கை அறை, கழிவறை, மாடிப்படி, தண்ணீர்த் தொட்டி.

எந்தத் திசை பார்த்த வீடு?

🧭கிழக்கு பார்த்த வீடுவாசல் எங்கே, எந்த அறை எங்கே.🧭வடக்கு பார்த்த வீடுவாசல் எங்கே, எந்த அறை எங்கே.🧭மேற்கு பார்த்த வீடுவாசல் எங்கே, எந்த அறை எங்கே.🧭தெற்கு பார்த்த வீடுவாசல் எங்கே, எந்த அறை எங்கே.

வாஸ்து மண்டலம்

வீட்டை ஒன்பது கட்டங்களாகப் பிரித்துப் பார்ப்பது வாஸ்துவின் அடிப்படை. நான்கு மூலைகளும் பஞ்சபூதங்களில் ஒவ்வொன்றைக் குறிக்கின்றன — வடகிழக்கு நீர், தென்கிழக்கு நெருப்பு, தென்மேற்கு நிலம், வடமேற்கு காற்று; நடு ஆகாயம். ஒவ்வொரு திசைக்கும் ஒரு காவல் தேவதை உண்டு.

படத்தில் மேலே வடக்கு. உங்கள் வீட்டின் நடுவில் நின்று, போனின் திசைகாட்டி (compass) மூலம் வடக்கைக் கண்டுபிடித்து ஒப்பிட்டுப் பாருங்கள்.

ஈசானிய மூலை

வடகிழக்கு · நீர் தத்துவம் · காவலர்: ஈசானன் (சிவன்)

வீட்டின் மிகப் புனிதமான மூலை. லேசாகவும், தாழ்வாகவும், திறந்தும், சுத்தமாகவும் வைக்க வேண்டிய இடம். காலைச் சூரிய ஒளி முதலில் நுழையும் திசை இது.

✓ ஏற்றவை
  • பூஜை அறை
  • வரவேற்பறை, திண்ணை
  • திறந்த வெளி, பெரிய ஜன்னல்கள்
  • சம்ப், ஆழ்துளைக் கிணறு, கிணறு
✗ தவிர்க்க
  • கழிவறை, செப்டிக் டேங்க்
  • சமையலறை
  • மாடிப்படி
  • கனமான அலமாரி, பொருள் சேமிப்பு
  • மேல்நிலைத் தண்ணீர்த் தொட்டி
  • உயரமான சுவர்

மனையின் மிகத் தாழ்வான பகுதி இதுவாக இருக்கட்டும்: தரை, கூரை, மழைநீர் எல்லாம் இந்தப் பக்கம் சரிந்து ஓடுவது நல்லது.

வெண்மைஇளமஞ்சள்வான நீலம்

கிழக்கு

கிழக்கு · காவலர்: இந்திரன், சூரியன்

சூரிய உதயமும் ஆரோக்கியமும் வரும் திசை. காலை வெயில் வீட்டைச் சுத்தமாகவும் உலர்வாகவும் வைக்கும்.

✓ ஏற்றவை
  • வரவேற்பறை
  • படிக்கும் அறை
  • பூஜை அறை
  • பெரிய ஜன்னல்கள், தலைவாசல்
✗ தவிர்க்க
  • கழிவறை
  • உயரமான சுவர், மரங்கள் (காலை வெயிலை மறைக்கும்)

மேற்கை விடக் கிழக்கில் அதிக காலியிடம் விடுவது வழக்கம்.

இலைப்பச்சைவெதுவெதுப்பான வெண்மைஇளம் பச்சைக்கல்

அக்னி மூலை

தென்கிழக்கு · நெருப்பு தத்துவம் · காவலர்: அக்னி

நெருப்பின் மூலை. சமையலறைக்கும் மின் சாதனங்களுக்கும் பாரம்பரிய இடம்.

✓ ஏற்றவை
  • சமையலறை
  • மின் பலகை, இன்வெர்ட்டர், ஜெனரேட்டர்
  • மின் மீட்டர்
✗ தவிர்க்க
  • சம்ப், நிலத்தடித் தண்ணீர்
  • பூஜை அறை
  • தம்பதியரின் படுக்கை அறை
  • மூலையில் தலைவாசல்

நெருப்பும் நீரும் சேரக் கூடாது: தண்ணீர்த் தொட்டிகளை இந்த மூலையில் வைக்க வேண்டாம்.

பீச்சுடுமண் நிறம்ரோஜா மணல்

தெற்கு

தெற்கு · காவலர்: யமன்

உறுதியும் ஓய்வும் தரும் திசை. இந்தியக் கோடையின் கடும் வெயில் தெற்கிலிருந்தே வருவதால், இங்கே கனமான சுவர்கள் வீட்டைக் குளிர்ச்சியாக வைக்கும்.

✓ ஏற்றவை
  • படுக்கை அறைகள்
  • மாடிப்படி
  • கனமான பொருள் சேமிப்பு
✗ தவிர்க்க
  • சம்ப், கிணறு
  • பெரிய திறந்த வெளி

வடக்கை விடத் தெற்கில் குறைவான காலியிடம் விடுவது வழக்கம்.

பவள மண்வெதுவெதுப்பான பழுப்புசெங்கல் சாயல்

கன்னி மூலை

தென்மேற்கு · நிலம் தத்துவம் · காவலர்: நிருதி

பூமியின் மூலை — வீட்டின் மிகக் கனமான, உறுதியான பகுதி. குடும்பத் தலைவருக்கு உரிய இடம்.

✓ ஏற்றவை
  • குடும்பத் தலைவரின் படுக்கை அறை
  • மாடிப்படி
  • கனமான அலமாரிகள்
  • மேல்நிலைத் தண்ணீர்த் தொட்டி (வீட்டின் மிக உயரமான இடம்)
✗ தவிர்க்க
  • தலைவாசல்
  • கழிவறை, செப்டிக் டேங்க்
  • சம்ப், ஆழ்துளைக் கிணறு, எந்தக் குழியும்
  • பெரிய ஜன்னல், திறந்த வெளி
  • சமையலறை

மனையின் மிக உயரமான, கனமான இடம்: மேல்நிலைத் தொட்டியும் உயரமான சுற்றுச்சுவரும் இங்கே.

மண் பழுப்புகளிமண் நிறம்பிஸ்கட் நிறம்

மேற்கு

மேற்கு · காவலர்: வருணன்

நிலைத்த வருமானமும் உறுதியும் தரும் திசை. மதிய வெயிலைத் தடுக்க இந்தப் பக்கச் சுவர்கள் கனமாக இருப்பது நல்லது.

✓ ஏற்றவை
  • பிள்ளைகளின் அறை
  • சாப்பாட்டு அறை
  • படிக்கும் அறை
  • மேல்நிலைத் தொட்டி
✗ தவிர்க்க
  • பெரிய திறந்த வெளி
  • சம்ப்

மேற்கு உயர்ந்தும் கிழக்கு தாழ்ந்தும் இருப்பது வழக்கமான நியதி.

சிலேட் நீலம்புறா சாம்பல்மங்கிய வெண்மை

வாயு மூலை

வடமேற்கு · காற்று தத்துவம் · காவலர்: வாயு

அசைவும் மாற்றமும் உள்ள மூலை. வந்து போகும் மனிதர்களுக்கும் பொருட்களுக்கும் ஏற்ற இடம்.

✓ ஏற்றவை
  • விருந்தினர் அறை, வளர்ந்த பிள்ளைகளின் அறை
  • கழிவறை
  • தானியக் கிடங்கு
  • வாகன நிறுத்தம்
  • செப்டிக் டேங்க் (சுவரிலிருந்து தள்ளி)
✗ தவிர்க்க
  • குடும்பத் தலைவரின் படுக்கை அறை
  • பூஜை அறை
  • சம்ப் (நிலத்தடித் தொட்டி)

சமையலறைக்கு அடுத்த நல்ல இடம் இதுவே — காற்று நெருப்புக்குத் துணை.

முத்துச் சாம்பல்க்ரீம்மென்வெண்மை

வடக்கு

வடக்கு · காவலர்: குபேரன் (செல்வம்)

செல்வமும் வாய்ப்புகளும் வரும் திசை. மென்மையான, கண்கூசாத வெளிச்சம் நாள் முழுவதும் கிடைக்கும்.

✓ ஏற்றவை
  • வரவேற்பறை
  • படிக்கும் அறை
  • தலைவாசல், ஜன்னல்கள்
  • பணப்பெட்டி (வடக்கு நோக்கித் திறக்கும்படி)
✗ தவிர்க்க
  • கழிவறை
  • மாடிப்படி
  • கனமான கட்டுமானம்

தெற்கை விட வடக்கில் அதிக காலியிடம் விடுவது வழக்கம்.

இளம்பச்சைமென்நீலம்தந்த நிறம்

பிரம்மஸ்தானம்

நடு · ஆகாயம் தத்துவம் · காவலர்: பிரம்மா

வீட்டின் இதயம். பழைய தமிழ் வீடுகளில் இது வானம் பார்த்த முற்றம். திறந்தும் ஒழுங்காகவும் வைக்க வேண்டிய இடம்.

✓ ஏற்றவை
  • முற்றம் அல்லது திறந்த ஹால்
  • குடும்பம் கூடும் இடம்
✗ தவிர்க்க
  • கழிவறை
  • மாடிப்படி
  • தூண், கனமான சுவர்
  • குழி, தொட்டி

நடுப்பகுதியில் எதையும் அடைத்து வைக்காமல், காற்றும் வெளிச்சமும் புழங்கும்படி வைத்திருங்கள்.

சுண்ணாம்பு வெண்மைமணல் நிறம்

எல்லா வீட்டுக்கும் பொதுவானவை

🧭 தூங்கும் திசை: தெற்கு அல்லது கிழக்கில் தலை வைத்துத் தூங்குவது வழக்கம். வடக்கில் தலை வைத்துத் தூங்குவது தவிர்க்கப்படுகிறது. மாணவர்களுக்குக் கிழக்கு சிறந்தது என்பது நம்பிக்கை.
