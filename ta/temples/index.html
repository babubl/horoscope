கோயில் வழிகாட்டி: நவக்கிரக மற்றும் பரிகாரக் கோயில்கள்

கும்பகோணத்தைச் சுற்றியுள்ள ஒன்பது நவக்கிரகக் கோயில்கள், தஞ்சைப் பெரிய கோயில், திருமணம், குழந்தைப் பேறு, நீண்ட ஆயுள், முன்னோர் கடனுக்காகக் குடும்பங்கள் செல்லும் கோயில்கள் — மூலவர், வரலாறு, அங்கு செய்யப்படும் பரிகாரம், தரிசன நேரம், செல்லும் வழி.

ஒன்பது நவக்கிரகக் கோயில்கள்

ஒன்பதும் காவிரி டெல்டாவில், கும்பகோணத்திலிருந்து சுமார் 60 கி.மீ.க்குள் உள்ளன. பெரும்பாலானவை பழமையான சிவன் கோயில்கள்; அங்கு கிரகத்துக்குத் தனிச் சன்னதி உண்டு. சூரியனுக்கென்றே கட்டப்பட்ட கோயில் சூரியனார் கோயில் மட்டுமே.

ஒன்பது நவக்கிரகக் கோயில்களின் வரைபடம்

அளவுக்கு ஏற்ப வரையப்படாத மாதிரி வரைபடம். கோயிலைத் தொட்டால் அதன் பக்கம் திறக்கும்.

நவக்கிரக யாத்திரைத் திட்டம்

கும்பகோணத்தில் தங்குங்கள். காரில் ஒன்பது கோயில்களையும் ஒரு நீண்ட நாளில் அல்லது வசதியாக இரண்டு நாட்களில் தரிசிக்கலாம்.

முதல் நாள் — கும்பகோணத்தின் தெற்கு, மேற்கு

  1. சூரியனார் கோயில் — சூரியன்
  2. கஞ்சனூர் அக்னீஸ்வரர் கோயில் — சுக்கிரன்
  3. திருநாகேஸ்வரம் நாகநாதசுவாமி கோயில் — ராகு
  4. ஆலங்குடி ஆபத்சகாயேஸ்வரர் கோயில் — குரு (வியாழன்)
  5. திங்களூர் கைலாசநாதர் கோயில் — சந்திரன்

இரண்டாம் நாள் — கடற்கரை நோக்கி

  1. வைத்தீஸ்வரன் கோயில் — செவ்வாய் (அங்காரகன்)
  2. திருவெண்காடு சுவேதாரண்யேஸ்வரர் கோயில் — புதன்
  3. கீழப்பெரும்பள்ளம் நாகநாதசுவாமி கோயில் — கேது
  4. திருநள்ளாறு சனீஸ்வரன் கோயில் (தர்ப்பாரண்யேஸ்வரர்) — சனி

சூரியனார் கோயிலில் தொடங்கி திருநள்ளாற்றில் (சனி) முடிப்பது மரபு. கோயில்கள் மதியம் சுமார் 12:00 / 12:30 முதல் மாலை 4:00 வரை மூடப்படும்; காலை, மாலைச் சுற்றுகளை அதற்கேற்பத் திட்டமிடுங்கள்.
